# Análisis Exploratorio de Datos - Hubway

## Autor
Guerra Chura Joan Leonardo

## Descripción

Este proyecto desarrolla un análisis exploratorio del dataset Hubway, un sistema de bicicletas compartidas de Boston (2011-2013).

Se aplican técnicas de:

- Data Wrangling
- Análisis exploratorio de datos
- Detección de valores faltantes
- Identificación de outliers
- Visualización de patrones temporales y espaciales

## Dataset

Hubway Bike Sharing Dataset.

## Objetivo

Analizar los patrones de uso del sistema e identificar problemas potenciales en los datos mediante un enfoque espacio-temporal.
